# Brahma Teja Punnamaraju — Portfolio

Personal portfolio site: Data Scientist · Generative AI & ML · Chicago, IL.

**Live site:** https://brahmateja96-mech.vercel.app/

A single static page (`index.html`) with no build step. It covers experience, selected projects, skills, and SarthAI, a side venture in relational intelligence.

## Files

| File | Purpose |
|---|---|
| `index.html` | The whole site — markup, styles and scripts |
| `resume.pdf` | Resume linked from the Resume buttons |
| `og-image.png` | 1200×630 preview image for LinkedIn and other link previews |
| `favicon.svg` | Browser tab icon |
| `logo-bg.webp` | Compressed SarthAI background image |
| `LinkedinAutomation/` | Separate LinkedIn posting script (not part of the site) |

## Updating

- **Resume:** replace `resume.pdf` with a file of the same name.
- **Content:** edit `index.html` directly. Keep titles, dates and numbers in sync with the resume.

## Publishing

Live site is deployed on Vercel from the private `portfolio_96-mech` repo; keep the two in sync.
